독서로 영역 FAQ — 전체 내용

Q01. 독서로에서 새롭게 업데이트 된 기능은 어떤 것들이 있나요?
A01. 정기/수시 패치를 통해 업데이트가 진행되고 있습니다. 새롭게 추가된 기능들을 공지사항의 포스터와 카드뉴스를 통해 안내 드리고 있습니다.

Q02. 도서관 책을 검색할 때 내가 원하는 조건만 골라보는 기능이 있나요?
A02. 새롭게 개선된 상세 필터 기능을 활용하면 됩니다. 도서분류, ISBN, 저자/역자, 발행처, 발행년도 등을 필터링하여 검색할 수 있습니다.

Q03. 독후활동 작성할 때 맞춤법이 맞는지 매번 확인하기 번거로운데, 사이트 내에서 바로 검사할 수 있나요?
A03. 신규 추가된 기능으로 맞춤법 검사기가 추가되었습니다. 독후활동을 작성한 후 검사하기 버튼을 클릭하면 맞춤법이 수정된 교정안을 제안해줍니다.

Q04. 손으로 직접 작성한 독후활동을 일일이 타이핑하지 않고 간편하게 옮겨 적을 방법이 있나요?
A04. 신규 추가된 OCR 문장 인식기능을 통해 가능합니다. 독후활동 작성 시 손글씨로 독후감 작성하기에 독후감을 업로드하여 기능을 활용해 보세요.

Q05. 독후활동은 어떻게 하나요?
A05. 독서로(read365.edunet.net) 로그인 → 독서활동 → 독후활동 → 나의 최근 대출 도서 또는 도서찾기를 통하여 독후활동이 가능합니다. 도서찾기에서 우리학교에 해당 도서가 없는 경우 독서로 상단 도서명 또는 저자를 입력하여 도서 검색 → 보기옵션을 시도내 타도서관으로 변경 → 도서 이미지 클릭 → 독후활동하기 버튼을 클릭하여 감상문 작성이 가능합니다. 단, 독서활동을 참여하기 위해서는 DLS 인증이 필수입니다.

Q06. 중학교, 고등학교로 진급 시 독서로에 새로 회원가입 하나요?
A06. 신규 가입이 아닌, 에듀넷(edunet.net)에서 학생 로그인 후 회원정보 변경에서 학교를 변경 후 변경한 학교의 새로운 대출증번호로 DLS인증을 해주시면 됩니다.

Q07. 독후활동할 때 최소 글자 수 제한은 없나요?
A07. 학교별 설정에 따라 다를 수 있습니다.

Q08. 독서로 메인화면 우리학교 독후활동 왕과 우리학교 독서왕의 선정 기준이 무엇인가요?
A08. 우리학교 독후활동왕: 우리학교 내에서 3개월동안 독후활동을 가장 많이 작성한 사용자로 통계 집계되어 선정됩니다. 우리학교 독서왕: 우리학교 내에서 오늘 일자부터 3개월 이전 기간 동안 대출건수가 가장 많은 사용자로 통계가 집계되어 선정됩니다.

Q09. 독후활동을 작성했는데, 독후활동 둘러보기에서 보이지 않아요.
A09. 독후활동 등록 시 선생님 승인요청을 예로 선택한 경우 선생님 승인 전까지는 조회되지 않습니다. 공개범위를 비공개로 작성한 독후활동의 경우 나의 독후활동에서 조회 가능합니다.

Q10. 학생이 작성한 독후활동 승인은 어떻게 할 수 있나요?
A10. 독서로 교사 로그인 후 독후활동 관리에서 진행상태가 대기인 게시글 클릭 후 확인여부 – 확인처리 클릭 시 승인처리 됩니다. 단, 반려처리 시 선생님 의견은 필수로 입력하여야 합니다.

Q11. 교사가 학생의 독후활동 공개범위를 수정할 수 있나요?
A11. 학생이 작성한 독후활동 게시글의 공개범위 수정은 불가합니다.

Q12. 나의 독후활동이 사라져서 갑자기 보이지 않아요.
A12. 에듀넷 계정, 에듀넷 소셜 계정, 교사 발급 계정 등 아이디가 여러 개인 경우일 수 있습니다. 아이디, 패스워드 찾기를 진행 바랍니다. 또는 독후활동 중 임시저장을 한 상태인지 확인해주시기 바랍니다. 임시저장은 독후활동 → 나의독후활동 → 임시저장 탭에서 확인이 가능합니다.

Q13. 학생들의 감상문 조회는 어떻게 하나요?
A13. 독서로(read365.edunet.net) 로그인 → 독서활동 → 독서이음활동 → 독서이음활동 생성 및 생성한 그룹 클릭하여 학생의 감상문 조회가 가능합니다.

Q14. 독서이음활동 생성 및 독서이음활동 삭제를 어떻게 하나요?
A14. 독서로(read365.edunet.net) 로그인 → 독서활동 → 독서이음활동 → 독서이음활동 생성 및 생성한 그룹 클릭 → 독서이음활동 관리 → 독서이음활동 삭제를 통해 삭제가 가능합니다.

Q15. 검색대 PC를 사용하는 경우 우리학교 자료검색을 어떻게 하나요?
A15. (비로그인) 도서검색 → 우리학교 도서검색 → 학교찾기 → 학교명 체크박스 체크 → 주소복사 → 해당 URL주소를 브라우저에 즐겨찾기해서 사용 또는 바탕화면에 아이콘 생성(바탕화면 마우스 오른쪽 클릭 > 새로 만들기 > 바로가기 > 항목 입력 위치에 복사한 URL 주소 붙여넣기 > 다음 > 이름 입력 > 마침)

Q16. 에듀넷 가입 후 독서로 대출증번호로 DLS인증을 어떻게 하나요?
A16. 독서로(read365.edunet.net) 로그인 → 마이페이지 → 도서관 이용 현황 → DLS 인증 → 소속도서관이 현재 우리학교와 일치한지 확인 → 학교에서 발급해준 대출증번호 입력 → 인증하기 버튼을 클릭하여 인증 가능합니다.

Q17. 독서로 회원가입 및 로그인은 어떻게 하나요?
A17. 독서로(read365.edunet.net) 접속 → 회원가입 → 에듀넷(edunet.net) 사이트에서 회원가입 및 소셜 회원가입이 가능하며 회원가입 후 독서로에서 해당 에듀넷 계정으로 로그인이 가능합니다.

Q18. 독서로는 시도별 사이트 주소가 다른가요?
A18. 독서로(read365.edunet.net)는 17개 시도가 통합된 사이트로, 하나의 주소를 사용합니다.

Q19. 우리학교의 책은 어디에서 검색하나요?
A19. (비로그인) 도서검색 → 우리학교 도서검색 → 학교찾기 → 학교명 체크박스 체크 → 검색어를 입력하여 도서 검색 또는 URL 주소를 새 창에 붙여넣기하여 새 창에서 우리학교 도서검색이 가능합니다. (로그인) 상단 도서명 또는 저자를 입력하세요 입력창에 도서 검색 시 우리학교 도서검색이 가능합니다.

Q20. 아이디랑 비밀번호를 분실한 경우 어떻게 하나요?
A20. 독서로(read365.edunet.net) 접속 → 아이디/비밀번호 찾기 에듀넷(edunet.net)에서 아이디 찾기, 비밀번호 찾기가 가능합니다.

Q21. 회원탈퇴는 어떻게 하나요?
A21. 에듀넷(edunet.net) 접속 → 로그인 → 회원정보 → 회원탈퇴 클릭

Q22. 학교가 이전 학교 혹은 다른 학교로 나오는 경우 어떻게 변경하나요?
A22. 에듀넷(edunet.net) 접속 → 로그인 → 회원정보 → 회원정보변경 클릭

Q23. 에듀넷에서 교사가 학생, 일반으로 가입한 경우 또는 학생이 일반으로 가입한 경우 어떻게 변경하나요?
A23. 에듀넷(edunet.net) 접속 → 로그인 → 회원정보 → 회원정보변경 클릭

Q24. 나의 학교도서관 이용 현황을 어떻게 확인하나요?
A24. 독서로(read365.edunet.net) 로그인 → 마이페이지 → 도서관 이용 현황 → 도서관 이용 현황 → 대출현황/대출이력/예약현황 등 확인이 가능합니다.

Q25. 에듀넷 계정의 이름, 생년월일, 성별을 수정하려면 어떻게 해야 하나요?
A25. 1544-0079 에듀콜센터로 연락주시거나, 에듀넷·티-클리어 고객센터 → 1:1 문의/제안에 변경하실 이름, 생년월일, 성별 정보를 남겨주시면 문의 내용 확인 후 변경 처리됩니다. (처리시간: 접수일로부터 1~2일 소요)

Q26. 독서이음활동에서 탈퇴하고 싶어요.
A26. (학생/참여교사) 독서이음활동 상세(독서이음활동 메인화면)에서 탈퇴 버튼을 클릭합니다. (생성교사) 독서이음활동관리의 독서이음활동삭제 버튼을 클릭합니다. 독서이음활동 삭제를 하는 경우 해당 활동그룹이 삭제됩니다.

Q27. 대출증번호로 DLS인증 시 입력값과 일치하는 이용자가 없습니다 문구가 나오면 어떻게 하나요?
A27. 대출증번호 영문이 포함된 경우 대문자로 작성 및 에듀넷에 가입한 이름과 학교도서관 DLS 시스템에 등록된 이름이 동일해야만 인증이 됩니다. 에듀넷에 이름이 정확한 경우 학교도서관 DLS관리자에게 문의 바랍니다. 또한, DLS인증–소속도서관 정보가 대출증 번호의 소속 정보와 일치하는지 확인이 필요합니다. 소속 도서관이 다를 경우 소속도서관–변경하기 버튼 클릭 후 학교찾기를 하시면 됩니다.

Q28. 에듀넷 아이디를 수정하고 싶은데 가능한가요?
A28. 아이디 수정은 불가능하며, 회원탈퇴 후 원하는 아이디로 재가입 해주셔야 합니다. 회원탈퇴 시 정보 및 개인자료가 영구 삭제되어 복구할 수 없습니다. 중요한 자료는 미리 확인하여 백업해주시기 바랍니다. 회원탈퇴 후, 동일 아이디로는 5일 동안 재가입이 불가합니다.

Q29. 마이페이지 대출상태가 대출불가라고 확인됩니다. 어떻게 처리해야 하나요?
A29. 에듀넷 가입 후 독서로 로그인 후 DLS인증을 받지않은 경우 대출불가로 확인되며, DLS 인증 시 대출가능으로 변경됩니다. 인증 후 동일하게 대출불가로 나오는 경우 현재 연체중인 도서가 있는지 확인해 주시길 바랍니다.

Q30. 감상문 작성 시 나이스와 연동되어서 자동으로 기록이 가능한가요?
A30. 나이스와 연동되어 있지 않습니다. 나이스에 독후활동 기록을 해야 한다면 독서로를 참고하여 선생님께서 수기로 기록 부탁드립니다.

Q31. 독후감 대회를 만들 수 없어요.
A31. 독후감 대회는 독서로 센터관리자가 생성·운영하는 서비스입니다.

Q32. 독서로 학교관리자 인증서 등록을 어떻게 하나요?
A32. 독서로 학교관리자(read365-school.edunet.net/Login) 접속 → 인증서 등록 클릭 → 독서관리자 ID/PW 입력 → 등록하기 클릭 → 관리자로 등록할 인증서 클릭 → 인증서 암호 입력 후 등록

Q33. 독서로에 학생, 교사 가입 여부를 어떻게 확인하나요?
A33. 독서로 학교관리자(read365-school.edunet.net/Login) 로그인 → 시스템관리 → 교사 및 학생관리 → 학생관리/교사관리

Q34. 독서로에 감상문 최소 글자수 설정을 어떻게 하나요?
A34. 독서로 학교관리자(read365-school.edunet.net/Login) 로그인 → 시스템관리 → 최소 글자수 관리 → 띄어쓰기 포함/미포함 선택 및 글자수 작성 → 저장

Q35. 독서로 학교관리자 아이디, 비밀번호가 무엇인가요?
A35. 아이디: 학교 나이스코드번호 (조회방법: DLS로그인 후 환경설정>기관정보>학교정보설정 화면에서 나이스학교코드 확인). 초기 비밀번호: DLS 공지사항–센터공지사항–독서로 학교관리자 페이지 및 독서로 관리 바로가기 이용 안내(2024.4.1.)를 참고해주시면 됩니다.

Q36. 독서로 학교관리자 비밀번호를 변경 후 분실한 경우 어떻게 하나요?
A36. 지역 시도 지원센터로 문의하여 독서로 학교관리자 비밀번호 초기화 요청 바랍니다.

Q37. 독서활동 저장 및 출력을 어떻게 하나요?
A37. 개별 저장 및 출력: 독서활동 → 독후활동 → 나의 독후활동 → 감상문명 클릭 → PDF 저장 → PDF 미리보기 → PDF 저장 클릭 후 파일 다운로드 후 해당 파일로 출력. 포트폴리오 저장 및 출력: 독서활동 → 독후활동 → 포트폴리오 → 포트폴리오 만들기 → 제목, 내용, 공개범위, 독후활동 추가 → 등록하기 → 포트폴리오 → 나의 포트폴리오 → 포트폴리오 클릭 → PDF 저장 → PDF 미리보기 → PDF 저장 클릭 후 파일 다운로드 후 해당 파일로 출력
