===== 독서로 이용자 매뉴얼 2026 (출처: 독서로 이용자 매뉴얼_2026.hwp) =====

[ 독서로 기본 안내 ]

독서로(read365.edunet.net)는 전국 17개 시도교육청이 통합 운영하는 학교도서관 독서교육 플랫폼입니다.
학교관리자 사이트: read365-school.edunet.net
에듀콜센터: 1544-0079

[ 1단계: 회원가입 방법 ]

■ 에듀넷 회원가입 (독서로 이용의 전제 조건)
1. 에듀넷(edunet.net) 접속
2. 회원가입 클릭
3. 이용약관 동의
4. 회원유형 선택 (학생 / 교원 / 학부모 / 일반)
5. 이름, 생년월일, 아이디, 비밀번호 입력
6. 이메일 인증 또는 휴대폰 인증 완료
7. 가입 완료 후 독서로(read365.edunet.net)에서 에듀넷 계정으로 로그인

■ 소셜 계정으로 가입하는 경우
- 카카오, 네이버 등 소셜 계정으로도 에듀넷 가입 가능
- 소셜 가입 후에도 독서로 로그인 동일하게 이용 가능

[ 2단계: DLS 인증 방법 ]

■ DLS 인증이란?
학교도서관 대출 시스템(DLS)에 등록된 대출증번호로 인증하는 절차입니다.
DLS 인증을 해야만 도서 대출이 가능합니다.

■ DLS 인증 절차
1. 독서로(read365.edunet.net) 로그인
2. 상단 메뉴 마이페이지 클릭
3. 도서관 이용 현황 클릭
4. DLS 인증 클릭
5. 소속도서관 확인 (현재 소속 학교와 일치하는지 확인)
   - 소속도서관이 다른 경우: 변경하기 버튼 클릭 → 학교찾기
6. 학교에서 발급받은 대출증번호 입력
   - 영문 포함 시 반드시 대문자로 입력
7. 인증하기 버튼 클릭
8. 인증 완료 후 대출 가능 상태로 변경

■ DLS 인증 오류 해결
- '입력값과 일치하는 이용자가 없습니다': 에듀넷 이름과 DLS 등록 이름이 동일해야 함
- 이름이 정확한데도 오류: 학교도서관 DLS 관리자에게 문의
- 대출불가 상태 지속: 연체 도서 반납 여부 확인

[ 3단계: 도서 검색 및 대출 ]

■ 로그인 상태에서 도서 검색
- 독서로 상단 검색창에 도서명 또는 저자 입력 → 우리학교 도서 우선 검색

■ 비로그인 상태에서 우리학교 도서 검색
1. 도서검색 클릭
2. 우리학교 도서검색 클릭
3. 학교찾기 클릭
4. 학교명 입력 후 체크박스 선택
5. URL 주소 복사 → 즐겨찾기 또는 바탕화면 바로가기 생성

■ 타 도서관 도서로 독후활동 하는 경우
- 독서로 상단 도서명 검색 → 보기옵션: '시도내 타도서관' 선택 → 해당 도서 이미지 클릭 → 독후활동하기

[ 4단계: 독후활동 작성 ]

■ 독후활동 작성 방법
1. 독서로(read365.edunet.net) 로그인
2. 독서활동 메뉴 클릭
3. 독후활동 클릭
4. '나의 최근 대출 도서' 또는 '도서찾기'에서 도서 선택
5. 독후활동하기 버튼 클릭
6. 감상문 작성 (맞춤법 검사기 활용 가능)
7. 선생님 승인요청 여부, 공개범위 설정 후 등록

■ 손글씨 독후감 업로드 (OCR 기능)
1. 독후활동 작성 화면에서 '손글씨로 독후감 작성하기' 선택
2. 손글씨 독후감 사진 업로드
3. OCR 자동 인식 → 텍스트 변환 확인
4. 수정 후 등록

■ 독후활동 PDF 저장 및 출력
[개별 출력]
1. 독서활동 → 독후활동 → 나의 독후활동
2. 감상문 제목 클릭 → PDF 저장 → PDF 미리보기
3. PDF 저장 클릭 → 파일 다운로드 → 출력

[포트폴리오 출력]
1. 독서활동 → 독후활동 → 포트폴리오 → 포트폴리오 만들기
2. 제목, 내용, 공개범위, 독후활동 추가 → 등록하기
3. 나의 포트폴리오 → PDF 저장 → 출력

[ 5단계: 독서이음활동 ]

■ 독서이음활동이란?
교사가 그룹을 생성하고 학생들이 함께 같은 책을 읽고 감상문을 공유하는 협력 독서 활동입니다.

■ 독서이음활동 그룹 생성 (교사)
1. 독서로 로그인
2. 독서활동 → 독서이음활동
3. 독서이음활동 생성 클릭
4. 활동명, 대상 도서, 참여 기간 설정
5. 학생 초대 (학생은 그룹 참여 후 감상문 작성)

■ 학생 감상문 조회 (교사)
독서활동 → 독서이음활동 → 생성한 그룹 클릭 → 학생별 감상문 조회

■ 독서이음활동 탈퇴/삭제
- 학생·참여교사: 독서이음활동 상세 화면에서 탈퇴 버튼 클릭
- 생성교사: 독서이음활동 관리 → 독서이음활동 삭제 (삭제 시 그룹 전체 삭제됨)

[ 교사 기능: 독후활동 관리 ]

■ 학생 독후활동 승인
1. 독서로 교사 계정 로그인
2. 독후활동 관리 메뉴 클릭
3. 진행상태 '대기'인 게시글 클릭
4. 확인여부 → 확인처리 클릭 (승인)
   또는 반려처리 클릭 (반려 시 의견 필수 입력)

■ 최소 글자수 설정 (학교관리자)
read365-school.edunet.net/Login → 시스템관리 → 최소 글자수 관리 → 글자수 설정 → 저장

[ 학교관리자 기능 ]

■ 학교관리자 접속 정보
- 사이트: read365-school.edunet.net/Login
- 아이디: 학교 나이스코드번호
- 초기 비밀번호: DLS 공지사항 → 센터공지사항 참고

■ 학교관리자 주요 기능
- 교사/학생 가입 현황 확인: 시스템관리 → 교사 및 학생관리
- 감상문 최소 글자수 설정
- 학교관리자 인증서 등록

■ 학교관리자 비밀번호 분실
지역 시도 지원센터로 문의하여 비밀번호 초기화 요청

[ 계정 관련 자주 묻는 문제 ]

■ 아이디/비밀번호 분실
독서로(read365.edunet.net) → 아이디/비밀번호 찾기 → 에듀넷에서 처리

■ 학교 정보 변경 (진급 시)
에듀넷(edunet.net) → 로그인 → 회원정보 → 회원정보변경

■ 이름·생년월일·성별 수정
에듀콜센터(1544-0079) 또는 에듀넷 1:1 문의 (처리: 1~2일)

■ 아이디 변경
불가. 회원탈퇴 후 재가입 필요 (탈퇴 후 5일간 동일 아이디 재가입 불가, 자료 복구 불가)

■ 나이스 자동 연동 여부
나이스와 연동되지 않습니다. 독후활동 기록은 교사가 나이스에 수기로 입력해야 합니다.
